# بروتوكول التصحيح — من التشخيص إلى سجل التغييرات

> **الغرض:** منع النسخ الصامت، ومنع التعديل المزاجي، ومنع قبول تصحيح بلا مصدر.
>
> **القاعدة الحاكمة:** لكل مهمة **وضع عرض**. في المهام الإبداعية لا تقرير افتراضي عمّا «أخطأ فيه الذكاء الاصطناعي» ولا عمّا صُحح. وفي مهام التصحيح اسأل سؤالاً واحداً: **تقرير بالأخطاء المصححة أم نص مصحح فقط؟** واحتفظ بـ`change_manifest` سجلاً داخلياً للجودة، لا تُظهره إلا بطلب.
>
> **المرجع:** `arabic-grammar-skill/references/sources.yaml` و`source_policy.md`.

---

## ١. عقد التشغيل

قبل أي تعديل، أعلن:

```yaml
mode: proofread | edit | rewrite | translation-review
scope: grammar | meaning | style | all
severity_floor: blocking | major | minor | style
no_change_allowed: true | false
report: none | brief | full        # الافتراضي: none في الإبداع، ونسأل في التصحيح
report_requested: true | false
deliverables: [corrected, manifest_internal]  # التقرير اختياري
```

### ١.١ الأوضاع

| الوضع | ما يسمح به | ما يمنعه |
| :--- | :--- | :--- |
| **proofread** | إصلاح الأخطاء النحوية والدلالية والترقيمية | تغيير الأسلوب أو الصوت |
| **edit** | إصلاح الأخطاء + تحسين الأسلوب | تغيير المعنى أو البنية |
| **rewrite** | إعادة صياغة | تغيير المقصد أو الصوت |
| **translation-review** | مراجعة الترجمة + العرنجية + الأمانة | تغيير النص الأصلي |

### ١.٢ درجات الخطورة

| الدرجة | المعنى | أمثلة |
| :--- | :--- | :--- |
| **blocking** | تفسد المعنى أو النحو | «لن يفهموا» ← «ما فهموا»؛ «توقفت التفكير» |
| **major** | تُضعف الوضوح أو المطابقة | «تراءت» بدل «تراءى»؛ «عندما وجودي» |
| **minor** | ترقيم أو إملاء أو اتساق | مسافة قبل الفاصلة؛ همزة |
| **style** | تفضيل أسلوبي | «أكثر لطفاً» ← «ألطف» |

**القاعدة:** لا يُسلّم نص فيه خطأ `blocking` بلا إصلاح أو بلا سبب صريح لتركه.

### ١.٣ وضع العرض: تقرير أم نص فقط؟

| نوع المهمة | الافتراضي | السؤال | المخرج |
| :--- | :--- | :--- | :--- |
| **إنشاء / كتابة إبداعية** | النص فقط، بلا تقرير | لا تسأل إلا إذا ذكر المستخدم التقرير | النص، وتقرير موجز إن طُلب |
| **تصحيح / تدقيق** | النص المصحح فقط | اسأل سؤالاً واحداً: «تقرير بالأخطاء المصححة أم نص فقط؟» | حسب الجواب |
| **مراجعة ترجمة** | النص + ملاحظات موجزة إن طُلب | اسأل | حسب الجواب |
| **إعراب / شرح قاعدة** | الشرح المطلوب | لا تقرير أخطاء إلا إن طُلب | الشرح |

**قاعدة السؤال:** في مهمة تصحيحية، اسأل مرة واحدة فقط. لا تُعدد الأسئلة، ولا تفرض تقريراً. وإن لم يجب المستخدم، فسلّم **النص المصحح فقط**.

**قاعدة الإبداع:** لا تعرض «ما أخطأ فيه الذكاء الاصطناعي» ولا «ما صححته» في مهمة كتابية أو إبداعية، إلا إذا طلب المستخدم ذلك صراحةً. المهم أن يقرأ النص، لا أن يقرأ عن النص.

## ٢. المسار الثلاثي

### ٢.١ المرور الأول: التشخيص بلا تعديل

اقرأ النص كاملاً، ثم استخرج **جدول المرشحين**. لا تعدّل شيئاً في هذه المرحلة.

```yaml
- id: C1
  span: "ولا زلت أذكر"
  category: negation_past
  problem: "لا النافية دخلت على الماضي"
  proposed_fix: "ما زلت أذكر"
  source_id: nahw_wafi
  confidence: 0.95
  severity: blocking
```

**قاعدة:** إن لم تستطع ملء `category` و`source_id`، فليس مرشحاً بعد؛ ضعه في `unresolved`.

### ٢.٢ المرور الثاني: التحقق العدائي

لكل مرشح، حاول **نقضه** بأربعة أسئلة:

1. **المعنى:** هل هناك قراءة صحيحة تجعل الأصل سليماً؟
2. **النحو:** هل القاعدة تنطبق على هذا التركيب بعينه؟
3. **المصدر:** هل المصدر من الطبقة ١ أو ٢؟ وهل ينص على هذه المسألة؟
4. **السجل:** هل التغيير يحفظ صوت الكاتب ونبرته؟

**إن نجح النقض في واحدة، ارفض المرشح.** وسجّل سبب الرفض.

### ٢.٣ المرور الثالث: التحرير الأدنى

لا تُطبّق إلا المرشحين المقبولين. ثم أخرج:

- النص المعدّل.
- `change_manifest.json` (داخلي).
- `unresolved` (داخلي).
- التقرير **إن طُلب** فقط.

## ٣. بوابات حفظ المعنى

قبل قبول أي تعديل، افحص:

| البوابة | السؤال | مثال فاشل |
| :--- | :--- | :--- |
| **الزمن** | هل تغيّر الماضي/المستقبل؟ | «لن يفهموا» ← «ما فهموا» |
| **النفي** | هل تغيّرت polarity؟ | «لا شيء» ← «ما من سيء» |
| **الدلالة** | هل تغيّر معنى الكلمة؟ | «اقتنعت» ← «قنعت» |
| **التعدية** | هل حُذف حرف الجر؟ | «توقفت التفكير» |
| **المطابقة** | هل تغيّر الفاعل أو عدده؟ | «تراءى» ← «تراءت» |
| **الإحالة** | هل تغيّر مرجع الضمير؟ | «هو» ← «هي» بلا سبب |
| **الكم** | هل تغيّر عدد أو كمية؟ | «ثلاث» ← «ثلاثة» |
| **الأعلام** | هل تغيّر اسم أو تاريخ؟ | «سيروس» ← «الشعرى» |
| **الصوت** | هل تغيّرت نبرة الراوي؟ | جملة ساخرة ← جملة رصينة |

**القاعدة:** أي تعديل يعبر بوابة منها يُرفض، إلا إذا كان مقصوداً ومعللاً ومصدره واضح.

**المرجع التفصيلي:** `meaning_gates.md` — تسع بوابات بمعايير القبول والأمثلة. و`voice_tests.md` — عشر حالات لاختبار الصوت، وطريقة تقييمها.

## ٤. قاعدة «لا نسخ صامت»

- إذا كان النص النهائي مطابقاً للأصل، فلا تقل «صُحح». قل: **«لا تغيير»**، واذكر ما فحصته.
- إذا كان التغيير الوحيد ترقيماً، فسمّه **«ضبط ترقيم»** لا **«تصحيح لغوي»**.
- إذا لم تجد خطأً في وضع `proofread`، فالمخرج الصحيح هو `no_change_reason`، لا نص مُعاد كتابته.
- `change_manifest` **سجل داخلي** للجودة والمراجعة، لا يُعرض تلقائياً.
- في المهمة الإبداعية لا تعرض «ما أخطأ فيه الذكاء الاصطناعي» ولا «ما صححته» إلا بطلب صريح.
- في مهمة التصحيح، اعرض التقرير فقط إذا اختار المستخدم «تقريراً». وإن اختار «نصاً فقط»، فسلّم النص بلا حواشٍ.

```yaml
no_change_reason: >
  فُحص النص في: الزمن، النفي، التعدية، المطابقة، الإحالة، الترقيم.
  لا يوجد خطأ blocking. المواضع الجائزة لم تُغيَّر.
```

## ٥. سجل التغييرات

كل تغيير يجب أن يظهر في `change_manifest.json` بهذا الشكل:

```json
{
  "candidate_id": "C1",
  "before": "ولا زلت أذكر",
  "after": "ما زلت أذكر",
  "category": "negation_past",
  "severity": "blocking",
  "reason": "لا النافية لا تدخل على الماضي هنا",
  "source_id": "nahw_wafi",
  "meaning_gates": {
    "tense": "preserved",
    "negation": "fixed",
    "lexical": "preserved",
    "reference": "preserved",
    "voice": "preserved"
  }
}
```

- `before` و`after` يجب أن يكونا مقطعين حرفيين من النص.
- `source_id` يجب أن يكون في `arabic-grammar-skill/references/sources.yaml`.
- `meaning_gates` تصف الأثر، لا مجرد كلمة «سليم».

## ٦. أمثلة من تقرير «حلم رجل مضحك»

### ٦.١ مرشحات مقبولة

| المرشح | الحكم | السبب |
| :--- | :--- | :--- |
| «بالنسبة لي» ← «في نظري/عندي» | **style** | عرنجية، لا خطأ نحوي |
| «فرحت أحدق» ← «فحدقت» | **major** | إزالة لبس بين `فَرِحْتُ` و`رُحْتُ` |
| «برهن لي» ← «برهن على» | **major** | تعدية معجمية |
| «ولا زلت» ← «ما زلت» | **blocking** | نفي الماضي |
| «إما يسخرون» ← «إنما يسخرون» | **blocking** | أداة ناقصة |
| «توقفت التفكير» ← «توقفت عن التفكير» | **blocking** | حذف حرف الجر |

### ٦.٢ مرشحات مرفوضة

| المرشح | سبب الرفض |
| :--- | :--- |
| «ينعتوني» بدل «ينعتونني» | جائز، وليس واجباً؛ الأصل سليم |
| «ما فهموا» بدل «لن يفهموا» | يغيّر الزمن |
| «قنعت» بدل «اقتنعت» | يغيّر الدلالة |
| «ما من سيء» بدل «لا شيء» | يغيّر المعنى |
| «عندما وجودي» | تركيب غير صحيح |
| «تراءت» بدل «تراءى» | خطأ في المطابقة |
| «على ازدياد علمي» | حرف جر لا يفيد الاستدراك |
| «لتلك» بدل «إلى تلك» | يغيّر معنى `عاد` |
| «وعلي أذنبت» | حرف جر + فعل |
| «شيئاً فشيئاً تعبير سيء» | الحكم نفسه خطأ |

### ٦.٣ مواضع محايدة لا تُعدّل في `proofread`

| الموضع | الحكم |
| :--- | :--- |
| «لقد ضحك» / «ضحك» | كلتاهما جائزة |
| «منذ» / «مذ» | كلتاهما جائزة |
| «لكنني» / «لكني» | كلتاهما جائزة |
| «أنني» / «أني» | كلتاهما جائزة |
| «أصبحت» / «صرت» | كلتاهما جائزة |
| «إلى الطاولة» / «عند الطاولة» | كلتاهما جائزة |

**القاعدة:** في `proofread`، لا تُغيّر الجائز. وفي `edit`، يمكن اقتراحه بوسم `style`.

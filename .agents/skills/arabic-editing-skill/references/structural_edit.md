# التحرير البنيوي — ملحق مهارة التحرير

> مستخلص من «الأسلوب» و«أصول النقد الأدبي» لأحمد الشايب. وال citations إلى الأبواب.

---

## ١. ما التحرير البنيوي؟

**التحرير البنيوي** هو النظر في النص كله: أطروحته، وبنائه، وترتيب أقسامه، وحجته، وجمهوره. وهو **قبل** تحرير الجملة والكلمة.

**قاعدته:** لا تُصلح فاصلة في فقرة سيُحذف نصفها.

---

## ٢. الأطروحة

### ٢.١ ما الأطروحة؟

**الأطروحة:** الجملة التي يريد الكاتب إثباتها أو إقناع القارئ بها.

**اختبارها:**
- هل يمكن صياغتها في جملة واحدة؟
- هل هي محددة، لا عامة؟
- هل يمكن الدفاع عنها؟
- هل النص كله يخدمها؟

### ٢.٢ مشكلات الأطروحة

| المشكلة | العلامة | العلاج |
| :--- | :--- | :--- |
| **غائبة** | النص سرد بلا دعوى | اقترح أطروحة |
| **متعددة** | كل فقرة تدّعي شيئاً | اختر واحدة |
| **واسعة** | «العلاج بالقرآن» | ضيّقها |
| **بديهية** | «التعليم مهم» | أضف زاوية |
| **غير قابلة للدفاع** | دعوى مطلقة | قيّدها |

### ٢.٣ صياغة الأطروحة

```text
أرى أن [الدعوى]، لأن [السبب]، وذلك في حدود [القيود].
```

**مثال:** «أرى أن تعليم النحو في المدارس يحتاج إلى سياق تطبيقي، لأن الطالب يحفظ القاعدة ولا يستعملها، وذلك في حدود المرحلة الثانوية.»

## ٣. الجمهور

| السؤال | الأثر |
| :--- | :--- |
| من يقرأ؟ | اللغة والمثال |
| ماذا يعرف؟ | ما تُشرحه وما تُفترضه |
| ماذا يريد؟ | ترتيب الأهم |
| ما يعارضه؟ | معالجة الاعتراض |
| ما يحساسيته؟ | تجنب الإساءة |

**قاعدة:** «لكل مقام مقال»؛ الخطاب للخاصة غير الخطاب للعامة.

---

## ٤. البناء

### ٤.١ النماذج

| النموذج | البنية | متى |
| :--- | :--- | :--- |
| **كلاسيكي** | مقدمة → عرض → خاتمة | مقال/بحث قصير |
| **حجاجي** | دعوى → دليل → اعتراض → رد → ترجيح | مقال فكري |
| **إصلاحي** | مشكلة → أسباب → حلول | مقال اجتماعي |
| **سردي** | بداية → عقدة → ذروة → حل | قصة |
| **وعظي** | نص → شرح → تطبيق → دعاء | خطبة |
| **تقريري** | خبر → تفاصيل → خلفية → أثر | خبر |

### ٤.٢ المقدمة

**وظائفها:**
1. جذب الانتباه.
2. تحديد الموضوع.
3. بيان الأطروحة.
4. بيان خطة النص.

**محاذير:** لا تُطل، ولا تبدأ باعتذار، ولا تُعلن ما لا تفعله.

### ٤.٣ العرض

- كل قسم فكرة واحدة.
- كل فكرة دليلها.
- الترتيب: الأهم للقارئ أولاً.
- الانتقالات واضحة.

### ٤.٤ الخاتمة

**وظائفها:**
1. تلخيص.
2. تأكيد الأطروحة.
3. دعوة/توصية.
4. فتح أفق.

**محاذير:** لا تُضف فكرة جديدة، ولا تُطل، ولا تُكرر حرفياً.

---

## ٥. الفقرة

### ٥.١ وحدة الفكرة

**القاعدة:** فقرة واحدة = فكرة واحدة.

**اختبار:** هل يمكن تلخيص الفقرة في جملة؟ إن لم يمكن، ففيها أكثر من فكرة.

### ٥.٢ البنية

```text
جملة موضوعية (الفكرة)
   ↓
جمل داعمة (شرح/دليل/مثال)
   ↓
جملة ختامية (ربط/نتيجة)
```

### ٥.٣ الترابط

- **الضمائر:** مرجعها واضح.
- **أدوات الربط:** لكن، لأن، لذلك، ثم.
- **التكرار المقصود:** لتثبيت الفكرة.
- **الإحالة:** «هذه الفكرة»، «ذلك».

**قاعدة:** لا تحذف رابطاً يحتاجه القارئ.

### ٥.٤ الطول

- ٣–٦ جمل للمقال.
- أطول في البحث.
- أقصر في الخبر/الإعلان.

### ٥.٥ الانتقال

- جملة تنبيه عند تغيير الموضوع.
- لا تترك القارئ يكتشف الانتقال وحده.

---

## ٦. الحجة

### ٦.١ عناصر الحجة

| العنصر | السؤال |
| :--- | :--- |
| **الدعوى** | ما الذي يُدّعى؟ |
| **الدليل** | ما الذي يسندها؟ |
| **التأويل** | كيف يدل الدليل؟ |
| **الاعتراض** | ما الذي يضعفها؟ |
| **الرد** | كيف تُدفع؟ |

### ٦.٢ المغالطات

| المغالطة | العلامة |
| :--- | :--- |
| **التعميم** | «كل الناس...» |
| **الاستدلال بالشهرة** | «مشهور، إذن صحيح» |
| **الشخصنة** | مهاجمة القائل لا القول |
| **المصادرة على المطلوب** | الدعوى في الدليل |
| **الخيار الزائف** | «إما... أو...» |
| **السلطة** | «قال فلان، إذن صحيح» |
| **الانزلاق** | تغيير معنى الكلمة |

### ٦.٣ الاعتراض

- اعرض أقوى اعتراض، لا أضعفه.
- اردّ بالدليل، لا بالشخص.
- إن لم تستطع، عدّل الدعوى.

## ٧. عيوب بنيوية

| العيب | العلامة | العلاج |
| :--- | :--- | :--- |
| **بلا أطروحة** | سرد بلا دعوى | اقترح أطروحة |
| **أطروحة متعددة** | كل فقرة دعوى | اختر واحدة |
| **بناء مبعثر** | لا ترتيب | أعد الخطة |
| **مقدمة طويلة** | تأخير الموضوع | اختصر |
| **خاتمة جديدة** | فكرة جديدة | احذف/أجّل |
| **حشو** | أقسام لا تخدم | احذف |
| **تكرار** | نفس الفكرة | ادمج |
| **انقطاع** | لا ربط | أضف انتقالاً |
| **اعتراض ضعيف** | رجل قش | اعرض الأقوى |

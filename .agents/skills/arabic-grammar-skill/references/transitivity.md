# التعدية وحروف الجر — مصائد التصحيح

> **القاعدة:** تغيير حرف الجر ليس تحسيناً أسلوبياً في الغالب؛ إنه **تغيير في المعنى**. لا تُبدّل `عن` بـ`من`، ولا `إلى` بـ`اللام`، ولا `الباء` بـ`على`، حتى تتحقق من المعجم ومن السياق.
>
> **المرجع:** `sources.yaml` — الطبقة ١ للقاعدة، والطبقة ٤ للدلالة.

---

## ١. الفرق بين اللازم والمتعدي

- **اللازم:** لا ينصب مفعولاً به، وقد يتعدى بحرف: `توقف عن`، `ذهب إلى`، `نام`.
- **المتعدي:** ينصب مفعولاً به: `كتب الكتاب`، `قرأ الدرس`.
- **المتعدي بحرف:** لا ينصب مفعولاً، لكنه يحتاج حرفاً: `اهتم بـ`، `فكر في`، `اقتنع بـ`.

**الخطأ الشائع:** حذف حرف الجر من فعل متعدٍ بحرف، فيصير النصب خطأً:
> ❌ «توقفت التفكير» ← ✅ «توقفت عن التفكير».

## ٢. جدول المصائد القاطعة

| الفعل | التعدية الصحيحة | الخطأ الشائع | المثال | ملاحظة |
| :--- | :--- | :--- | :--- | :--- |

| **اهتم** | اهتم **بـ** | اهتم لأمر | اهتم بأمره | «اهتمّ له بأمره» وردت، لكن «بأمره» أفصح |
| **برهن** | برهن **على** / أثبت | برهن لي | برهن على صحة الدعوى | «برهن لي» تعدية باللام غير مسموعة في المعاجم |
| **فكر** | فكر **في** | فكر بالانتحار | فكر في الانتحار | «فكر بـ» شائعة، و«في» أفصح |
| **اقتنع** | اقتنع **بـ** | اقتنع فيه | اقتنع بالفكرة | «اقتنع فيه» تجعل «في» ظرفاً، لا متعلقاً بالفعل |

## ٣. حروف متقاربة لا تُبدّل بلا تحقق

هذه ليست أخطاءً قاطعة؛ لكل تركيب معنى. لا تُصححها إلا بسياق يمنع غيرها:

| الفعل | الوجوه | الفرق |
| :--- | :--- | :--- |
| **استعان** | استعان **بـ** / **على** | «بـ» للاستعانة بالشيء، و«على» للاستعانة على الأمر |
| **شكر** | شكر **على** / **لـ** | «على» للسبب، و«لـ» للشخص |
| **عاتب** | عاتب **على** / **في** | «على» للسبب، و«في» للأمر |
| **لام** | لام **على** / **في** | «على» للسبب، و«في» للأمر |
| **غضب** | غضب **من** / **على** / **لـ** | «من» للسبب، «على» للتعدي، «لـ» للتعليل |
| **بكى** | بكى **على** / **من** / **لـ** | «على» للتفجع، «من» للسبب، «لـ» للتعليل |
| **خاف** | خاف **من** / **على** | «من» للخوف، «على» للخوف على الغير |
| **اعتذر** | اعتذر **عن** / **من** | «عن» للمجاوزة، «من» للابتداء |
| **ضحك** | ضحك **من** / **على** | «من» للاستهزاء، «على» قد تفيد الخدع أو الاستهزاء بحسب السياق |
| **رغب** | رغب **في** / **عن** | «في» للرغبة، «عن» للإعراض |
| **زهد** | زهد **في** / **عن** | «في» للزهد، «عن» للإعراض |
| **رضي** | رضي **بـ** / **عن** | «بـ» للقبول، «عن» للرضا |

**القاعدة:** إذا كان الحرفان جائزين بمعنيين، فالتغيير **أسلوبي**، لا **نحوي**. ولا تُبدّل بلا قرينة.

---

## ٤. كيف تتحقق قبل التعديل؟

1. **حدد نوع الفعل:** لازم أم متعدٍ؟ إن كان متعدياً بحرف، فما الحرف؟
2. **افتح المعجم:** ابحث عن الفعل في `المعجم العربي الجامع` أو `المعجم` أو `لسان العرب`.
3. **افحص المعنى:** هل الحرف الجديد يعطي معنى آخر؟ إن نعم، فلا تُبدّل.
4. **افحص السياق:** قد يكون الحرف الأصلي مقصوداً (مثل `عاد إلى` بمعنى الانتهاء، و`عاد لـ` بمعنى الملك).
5. **اذكر المصدر:** إن لم تجد نصاً، ضع الاقتراح في `unresolved`.

---

## ٥. قائمة فحص سريعة

- [ ] هل الفعل لازم أم متعدٍ؟
- [ ] هل الحرف الأصلي يفيد معنى مقصوداً؟
- [ ] هل الحرف البديل يفيد معنى آخر؟
- [ ] هل المعجم يذكر التعدية الأصلية؟
- [ ] هل المسألة خلافية؟ إن كانت، اذكر الخلاف.
- [ ] إن لم يوجد مصدر: هل نُقل إلى `unresolved`؟

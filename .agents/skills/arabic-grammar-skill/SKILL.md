# مهارة النحو والإعراب

> مبنية على **«جامع الدروس العربية»** لمصطفى الغلاييني (ثلاثة أجزاء)، و**«النحو الوافي»** لعباس حسن (أربعة أجزاء).
> ومسنودة بـ**`arabic-writing-skill`** في اللغة ونبذ العَرَنْجِيَّة، وبـ**`arabic-editing-skill`** في التحرير الشامل.

> **تنبيه:** هذه المهارة **لتصحيح النص وشرح قواعده وإعرابه**، لا لتدريس النحو كاملاً. ولا تُفتى في القراءات، ولا تُحسم المسائل الخلافية بلا مصدر. والقاعدة: **لا تصحيح بلا سبب، ولا إعراب بلا منهج، ولا حكم بلا كتاب.**

> **عقد التشغيل (v1.3):** لا تصحيح قاطع بلا `source_id` من `references/sources.yaml`. والتصحيح القاطع يحتاج طبقة ١ أو ٢. وما لا مصدر له يبقى اقتراحاً في `unresolved`. وراجع `references/source_policy.md` قبل أي حكم، و`references/transitivity.md` و`references/particle_traps.md` قبل تصحيح التعدية أو الأدوات، و`references/regression_cases.md` لقياس الاستدعاء والدقة. والقياس الآلي في `qalam-eval` (١٠٠ حالة، مشغّل، وخط أساس). وفي مهام التصحيح اسأل: «تقرير بالأخطاء المصححة أم نص مصحح فقط؟»؛ ولا تقرير افتراضي في المهام الإبداعية.

## ٠. قبل أن تبدأ: خمسة أسئلة

| السؤال | لماذا؟ | إن لم يُجب |
| :--- | :--- | :--- |
| **١. ما نوع النص؟** (فصيح / عامي / مترجم / أكاديمي / إعلامي / شعري) | يحدد مستوى التصحيح والمسموح | افترض فصيحاً معاصراً |
| **٢. ما المطلوب؟** (تصحيح / إعراب / شرح قاعدة / تدقيق شامل) | يحدد حجم الرد | اسأل، ولا تخلط الأربعة |
| **٣. ما مستوى القارئ؟** (مبتدئ / متوسط / متخصص) | يحدد عمق الشرح | متوسط |
| **٤. هل تريد النص المصحح فقط، أم تقريراً بالأخطاء المصححة، أم تعديلاً مشروحاً؟** | يحدد شكل المخرج | النص المصحح فقط |
| **٥. هل النص عاميّ مقصود؟** | لا تُحوّله إلى الفصحى بلا إذن | لا تُغيّر المستوى |

**أسئلة تكميلية:**
- هل تريد إعراب كل كلمة أم الكلمات المحورية؟
- هل هناك مصطلح نحوي تفضّله (مبتدأ/خبر، مسند/مسند إليه)؟
- هل النص لغير الناطقين بالعربية؟ (يبسّط الشرح)
- هل هناك موضع خلافي تريد عرضه؟

> **قاعدة:** في **مهام التصحيح**، اسأل سؤالاً واحداً: «تقرير بالأخطاء المصححة أم نص مصحح فقط؟». وإن لم يجب، فسلّم **النص المصحح فقط**. وفي **المهام الإبداعية** لا تقرير افتراضي عمّا «أخطأ فيه الذكاء الاصطناعي» ولا عمّا صُحح، إلا بطلب صريح. ولا تفترض «تصحيحاً مشروحاً» بلا سؤال.

## ١. المبادئ العشرة

1. **المعنى أولاً:** لا تصحح ما يفسد المعنى، ولا تغيّر مقصد الكاتب.
2. **أقل تعديل:** صحّح الخطأ، ولا تُعد صياغة النص كله.
3. **كل تعديل بسببه:** لا تقل «هذا أصح» بلا قاعدة.
4. **الشرح بقدر الحاجة:** جملة واحدة للمبتدئ، وتفصيل للمتخصص.
5. **لا تُحوّل العامية:** إن كان النص عامياً مقصوداً، صحّح داخله ولا تفرض الفصحى.
6. **لا تعرب بالحدس:** اتبع منهج الإعراب (الباب ٤).
7. **لا تجزم في الخلاف:** قل «على المختار»، «عند الجمهور»، «وفي المسألة خلاف».
8. **الترقيم جزء من المعنى:** لا تهمل الفاصلة والنقطة.
9. **احفظ صوت الكاتب:** لا تجعل أسلوبه أسلوبك.
10. **المرجع أمانة:** لا تنسب قاعدة إلى كتاب لم تراجعه.

## ٤. منهج الإعراب: ست خطوات

1. **حدد نوع الجملة:** اسمية أم فعلية؟
2. **حدد نوع الكلمة:** اسم، فعل، حرف؟
3. **حدد العامل:** ما الذي رفعها أو نصبها أو جرّها؟
4. **حدد الموقع:** مبتدأ، خبر، فاعل، مفعول، حال، تمييز…
5. **حدد العلامة:** أصلية أم فرعية؟ ظاهرة أم مقدرة؟
6. **اذكر السبب:** لماذا هذه العلامة؟

**مثال:**
> «إنّ العلمَ نافعٌ».
- **إنّ:** حرف توكيد ونصب مبني على الفتح، لا محل له من الإعراب.
- **العلم:** اسم «إنّ» منصوب، وعلامة نصبه الفتحة الظاهرة.
- **نافع:** خبر «إنّ» مرفوع، وعلامة رفعه الضمة الظاهرة.
- **الجملة:** اسمية، في محل رفع خبر لمبتدأ محذوف أو استئنافية.

**محاذير الإعراب:**
- لا تعرب الحرف.
- لا تعرب الماضي والأمر.
- لا تعرب المضارع المتصل بنون التوكيد أو نون النسوة إلا محلاً.
- لا تقل «مرفوع بالضمة» في المثنى؛ بل «بالألف».
- لا تقل «منصوب بالفتحة» في جمع المؤنث السالم؛ بل «بالكسرة».
- لا تنسَ «المحل من الإعراب» للجمل والمصادر المؤولة.

## ٥. الجملة الاسمية والفعلية

### ٥.١ الجملة الاسمية

| الركن | الحكم | مثال |
| :--- | :--- | :--- |
| **المبتدأ** | مرفوع، ولا يسبقه عامل | «العلمُ نورٌ» |
| **الخبر** | مرفوع، يخبر عن المبتدأ | «العلمُ نورٌ» |
| **الخبر المقدم** | جواز التقديم | «في الدار رجلٌ» |
| **المبتدأ المؤخر** | بعد شبه الجملة | «في الدار رجلٌ» |

**كان وأخواتها:** ترفع الاسم وتنصب الخبر: كان، أصبح، أضحى، أمسى، ظل، بات، صار، ليس، ما زال، ما دام، ما برح، ما فتئ، ما انفك.
> «كان اللهُ عليمًا».

**إنّ وأخواتها:** تنصب الاسم وترفع الخبر: إنّ، أنّ، كأنّ، لكنّ، ليت، لعلّ.
> «إنّ اللهَ رحيمٌ».

**ظن وأخواتها:** تنصب المبتدأ والخبر مفعولين: ظن، حسب، خال، زعم، رأى (بمعنى اعتقد)، علم، وجد، اتخذ، جعل.
> «ظننتُ العلمَ نافعًا».

### ٥.٢ الجملة الفعلية

| الركن | الحكم | مثال |
| :--- | :--- | :--- |
| **الفعل** | مبني أو معرب | «قام» / «يقوم» |
| **الفاعل** | مرفوع | «قام زهيرٌ» |
| **المفعول به** | منصوب | «أكرمتُ زهيرًا» |
| **نائب الفاعل** | مرفوع | «أُكرم زهيرٌ» |

**الفعل المعلوم:** له فاعل.
**الفعل المجهول:** له نائب فاعل.
**الفعل اللازم:** لا ينصب مفعولاً به.
**الفعل المتعدي:** ينصب مفعولاً أو أكثر.

## ٧. المنصوبات

> «منصوبات الأسماء أربعة عشر: المفعول به، والمفعول المطلق، والمفعول له، والمفعول فيه، المفعول معه، والحال، والتمييز، والمستثنى، والمنادى، وخبر الفعل الناقص، وخبر «ليس»، واسم «إن» أو إحدى أخواتها، واسم «لا» النافية للجنس، والتابع للمنصوب». — جامع الدروس العربية

| المنصوب | تعريف موجز | مثال |
| :--- | :--- | :--- |
| **المفعول به** | ما وقع عليه فعل الفاعل | «قرأتُ الكتابَ» |
| **المفعول المطلق** | مصدر منصوب يؤكد الفعل أو يبين نوعه/عدده | «فرحتُ فرحًا» |
| **المفعول لأجله** | مصدر قلبي علة للفعل | «قمتُ إجلالًا للعلم» |
| **المفعول فيه** | ظرف زمان أو مكان | «صمتُ يومَ الخميس» |
| **المفعول معه** | اسم بعد واو بمعنى «مع» | «سافرتُ والليلَ» |
| **الحال** | هيئة الفاعل أو المفعول | «جاء زهيرٌ مسرورًا» |
| **التمييز** | اسم يرفع الإبهام | «طاب محمدٌ نفسًا» |
| **المستثنى** | ما أخرج من الحكم بـ«إلا» وأخواتها | «جاء القومُ إلا زهيرًا» |
| **المنادى** | اسم بعد حرف نداء | «يا زهيرُ» |
| **خبر كان** | منصوب بعد كان وأخواتها | «كان زهيرٌ مجتهدًا» |
| **خبر ليس** | منصوب بعد ليس | «ليس زهيرٌ مجتهدًا» |
| **اسم إنّ** | منصوب بعد إنّ وأخواتها | «إنّ زهيرًا مجتهدٌ» |
| **اسم لا النافية للجنس** | منصوب أو مبني | «لا رجلَ في الدار» |
| **التابع للمنصوب** | نعت/عطف/بدل/توكيد تابع لمنصوب | «رأيتُ رجلًا كريمًا» |

## ٨. المجرورات

### ٨.١ حروف الجر

**أشهرها:** الباء، من، إلى، عن، على، في، الكاف، اللام، واو القسم، تاء القسم، مذ، منذ، رب، حتى، خلا، عدا، حاشا، كي، متى (لغة هذيل)، لعل (لغة عقيل).

**معانيها:** الابتداء، الانتهاء، السببية، الاستعانة، الظرفية، المصاحبة، التعليل، التوكيد، القسم.

### ٨.٢ الإضافة

| النوع | مثال | الحكم |
| :--- | :--- | :--- |
| **معنوية** | «كتابُ الطالبِ» | تفيد التعريف أو التخصيص |
| **لفظية** | «كاتبُ الدرسِ» | تفيد التخفيف |

**قواعد:**
- المضاف لا ينوّن، ولا تدخله «أل».
- المضاف إليه مجرور دائماً.
- لا يُضاف الاسم إلى مرادفه.
- لا يُضاف الموصوف إلى صفته.
- تُضاف الصفة إلى الموصوف بشرط صحة «من».

## ٩. التوابع

| التابع | تعريف | مثال |
| :--- | :--- | :--- |
| **النعت** | يصف متبوعه | «رأيتُ رجلًا كريمًا» |
| **العطف** | يتبع بوساطة حرف | «جاء زهيرٌ وعليٌّ» |
| **البدل** | المقصود بالحكم | «جاء أخوك زهيرٌ» |
| **التوكيد** | تكرير لتثبيت المعنى | «جاء زهيرٌ نفسه» |

**النعت:** حقيقي (يتبع ما قبله في الإعراب والتعريف والعدد) وسببي (يتبع ما بعده في التذكير والتأنيث).
**البدل:** مطابق، بعض من كل، بدل اشتمال.
**التوكيد:** لفظي (تكرار اللفظ) ومعنوي (نفس، عين، كل، جميع، كلا، كلتا).

| :--- | :--- |

| **يَفْعُلُ** | يكتب |

| **اسم تفضيل** | أفضل | زيادة في الصفة |
| **اسم مكان/زمان** | مكتب | مكان/زمان الفعل |
| **اسم آلة** | مفتاح | آلة الفعل |

### ١١.٣ الإعلال والإبدال والإدغام

- **الإعلال:** حذف حرف العلة، أو قلبه، أو تسكينه.
- **الإبدال:** إزالة حرف ووضع آخر مكانه.
- **الإدغام:** إدخال حرف في آخر متجانسين.

**أمثلة:**
- «قال» أصلها «قَوَل» → إعلال بالقلب.
- «وعد» → «يعد» → إعلال بالحذف.
- «مدّ» أصلها «مَدَد» → إدغام.

### ١١.٤ الجمع والتصغير والنسب

| النوع | مثال | قاعدة |
| :--- | :--- | :--- |
| **جمع مذكر سالم** | معلمون | يرفع بالواو، وينصب/يجر بالياء |
| **جمع مؤنث سالم** | معلمات | ينصب بالكسرة |
| **جمع تكسير** | كتب | يعرب بالحركات |
| **تصغير** | كتيّب | للتحقير أو التحبيب |
| **نسب** | علمي | يرد إلى المفرد |

### ١١.٥ الممنوع من الصرف

**يمنع من الصرف:** العلمية + التأنيث، العلمية + العجمة، العلمية + التركيب المزجي، العلمية + وزن الفعل، الوصفية + وزن «أفعل»، الوصفية + «فعلان»، صيغة منتهى الجموع، ألف التأنيث.

**حكمه:** لا ينوّن، ويُجر بالفتحة إذا لم يكن مضافاً ولا مقترناً بـ«أل».
> «مررتُ بأحمدَ» / «مررتُ بأحمدِ المدينةِ» (مضاف) / «مررتُ بالأحمدِ» (مع أل).

## ١٢. الإملاء والترقيم

### ١٢.١ الهمزات

| النوع | المواضع | مثال |
| :--- | :--- | :--- |
| **همزة وصل** | «ال»، «ابن»، «اسم»، «امرؤ»، «اثنان»، أمر الثلاثي، أمر الخماسي/السداسي | «اكتب»، «استخرج» |
| **همزة قطع** | الأسماء، الأفعال الرباعية ومصادرها، الحروف | «أحمد»، «إكرام» |

**الهمزة المتوسطة:** تُكتب على حرف يناسب أقوى الحركتين (الكسرة > الضمة > الفتحة > السكون).
**الهمزة المتطرفة:** بعد ساكن → على السطر؛ بعد متحرك → على حرف يناسب حركته.

### ١٢.٢ الألف اللينة

- في الأسماء الثلاثية: تُكتب قائمة إلا إذا كان أصلها ياءً («فتى»، «هدى»).
- في الأسماء فوق الثلاثية: تُكتب ياءً إلا إذا سبقت بياء («دنيا»).
- في الأفعال: تُكتب قائمة في الثلاثي إذا كان أصلها واواً («دعا»)، وياءً إذا كان أصلها ياءً («رمى»).

### ١٢.٣ التاء المربوطة والمفتوحة

- **مربوطة:** في الأسماء المؤنثة، وفي الجمع الذي لا ينتهي بجمع.
- **مفتوحة:** في الأفعال، وفي جمع المؤنث السالم، وفي بعض الأسماء («بيت»، «وقت»).

### ١٢.٤ الترقيم

| العلامة | الوظيفة |
| :--- | :--- |
| **النقطة (.)** | نهاية الجملة التامة |
| **الفاصلة (،)** | فصل الجمل القصيرة |
| **الفاصلة المنقوطة (؛)** | بين جملتين بينهما سبب ونتيجة |
| **النقطتان (:)** | بعد القول أو التفسير أو التمثيل |
| **علامة الاستفهام (؟)** | نهاية السؤال |
| **علامة التعجب (!)** | التعجب أو الانفعال |
| **الاعتراض (— —)** | جملة معترضة |
| **القوسان ( )** | تفسير أو إضافة |
| **علامات التنصيص (« »)** | نقل حرفي |

## ١٤. التصحيح قبل/بعد

### نموذج ١: خطأ إعرابي

**قبل:**
> «إنّ الطالبُ مجتهدٌ.»

**بعد:**
> «إنّ الطالبَ مجتهدٌ.»

**الشرح:**
- «إنّ» حرف توكيد ونصب.
- «الطالب» اسم «إنّ» منصوب بالفتحة.
- «مجتهد» خبر «إنّ» مرفوع بالضمة.

### نموذج ٢: خطأ في المطابقة

**قبل:**
> «ذهبت بفاطمة إلى السوق.»

**بعد:**
> «ذهب بفاطمة إلى السوق.»

**الشرح:**
- «ب» حرف جر زائد.
- «فاطمة» نائب فاعل مجرور لفظاً مرفوع محلاً.
- الفعل يبقى مذكراً لأن نائب الفاعل ليس فاعلاً حقيقياً مؤنثاً.

### نموذج ٣: خطأ في العدد

**قبل:**
> «حضر ثلاثةُ نساءٍ.»

**بعد:**
> «حضرت ثلاثُ نساءٍ.»

**الشرح:**
- العدد من ٣ إلى ١٠ يخالف المعدود.
- «نساء» مؤنث، فيُؤنث العدد.
- الفعل يُؤنث إذا كان الفاعل مؤنثاً.

### نموذج ٤: خطأ في الترقيم

**قبل:**
> «قال لي: لن أذهب، ثم عاد.»

**بعد:**
> «قال لي: لن أذهب. ثم عاد.»

**الشرح:**
- النقطة تفصل الجملتين المستقلتين.
- الفاصلة كانت تُوهم أن «ثم عاد» من تمام القول.

## ١٥. قائمة التدقيق النهائية

### أولاً: الإعراب
- [ ] نوع الجملة محدد.
- [ ] نوع كل كلمة محدد.
- [ ] العامل مذكور.

- [ ] السبب مذكور.

### ثانياً: التصحيح
- [ ] لم يتغير المعنى.
- [ ] كل تعديل له سبب.
- [ ] لم تُحوّل العامية إلى فصحى بلا إذن.
- [ ] المطابقة (تذكير/تأنيث/عدد) سليمة.
- [ ] الترتيب سليم.
- [ ] الحذف والزيادة مبرران.
- [ ] الهمزات والألف والتاء سليمة.
- [ ] الترقيم سليم.

- [ ] لا عرنجية (`من خلال`، `على صعيد`، `بالنسبة لـ`، `قام بـ`).
- [ ] لا حشو.
- [ ] لا تكرار.
- [ ] الجمل متناسقة.
- [ ] المصطلح موحد.

### رابعاً: العرض
- [ ] الشرح بقدر مستوى القارئ.
- [ ] الأمثلة واضحة.
- [ ] الجدول منظم.
- [ ] لا حكم في مسألة خلافية بلا تنبيه.
- [ ] المرجع مذكور.

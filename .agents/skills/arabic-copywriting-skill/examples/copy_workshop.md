# ورشة الإعلان: عشرة تمارين

> تمارين متدرجة، لكل تمرين: الهدف، التعليمات، نموذج، ومعيار التصحيح.

---

## التمرين ١: الجمهور

**الهدف:** تحديد شريحة واحدة.

**التعليمات:** خذ منتجاً، واكتب ثلاث شرائح، ثم اختر واحدة.

| الشريحة | الحاجة | لماذا اخترتها |
| :--- | :--- | :--- |
| طلاب | توفير | حساسون للسعر |
| أسر | فاتورة | قرار جماعي |
| موظفون | وقت | يدفعون للسرعة |

**معيار:** هل تستطيع وصف شخص واحد بالاسم؟

---

## التمرين ٢: الفائدة

**الهدف:** تحويل الميزة إلى فائدة.

| الميزة | الفائدة |
| :--- | :--- |
| بطارية ٥٠٠٠ | يوم بلا شاحن |
| توصيل مجاني | لا تدفع أكثر |
| تصنيف تلقائي | تعرف أين يذهب مالك |

**معيار:** هل الفائدة في حياة العميل، لا في المنتج؟

---

## التمرين ٣: الاعتراض

**الهدف:** الرد قبل الكتابة.

| الاعتراض | الرد |
| :--- | :--- |
| غالٍ | قارن بالتكلفة اليومية |
| معقد | ٣ خطوات |
| لا أثق | ضمان |

**معيار:** هل تركت اعتراضاً بلا رد؟

---

## التمرين ٤: الفكرة

**الهدف:** فكرة واحدة.

**التعليمات:** اكتب فكرة لكل مصدر: الاعتراض، اللحظة، المفارقة، الإنسان.

**نموذج:**
- «أعطِ كل ريال اسماً.»
- «فاتورتك أقل ٢٠٪.»
- «المكالمة التي لا تريدها.»
- «الرف الذي يعرفك.»

**معيار:** هل تصلح الفكرة لمنتج آخر؟ إن نعم، فليست محددة.

---

## التمرين ٥: العنوان

**الهدف:** عنوان يوقف ويصدق.

**التعليمات:** اكتب ١٢ عنواناً، ثم احذف كل ما لا يستطيع النص إثباته.

**نموذج:**
1. «فاتورتك أقل ٢٠٪.»
2. «٣ دقائق تكفي.»
3. «لماذا تدفع أكثر؟»
4. «أغلى قهوة… أرخص من فنجان.»
5. «لا تغيّر مزودك.»
6. «جرّبها مجاناً.»

**معيار:** هل يمرّ اختبار الصدق؟

---

## التمرين ٦: AIDA

**الهدف:** بناء رسالة كاملة.

```text
Attention: ...
Interest: ...
Desire: ...
Conviction: ...
Action: ...
```

**معيار:** هل كل مرحلة موجودة؟ هل يمكن حذف واحدة؟

---

## التمرين ٧: CTA

**الهدف:** فعل واحد.

| الموقف | CTA |
| :--- | :--- |
| منتج جديد | «جرّب مجاناً» |
| عرض | «احجز قبل الخميس» |
| محتوى | «اقرأ الدليل» |
| متجر | «أضف إلى السلة» |

**معيار:** هل تعرف ماذا سيحدث بعد الضغط؟

---

## التمرين ٨: الشعار

**الهدف:** فكرة في ٢–٥ كلمات.

**التعليمات:** اكتب خمسة شعارات لمنتج «تطبيق ميزانية».

**نموذج:**
- «كل ريال باسمه.»
- «اعرف أين يذهب.»
- «ميزانيتك، بلا ورق.»
- «قبل أن ينتهي الشهر.»
- «المال يتكلم.»

**معيار:** هل يصمد بلا صورة؟ هل يحمل فكرة؟

---

## التمرين ٩: صفحة هبوط

**الهدف:** ترتيب الإقناع.

```text
① عنوان
② لمن
③ صورة
④ ٣ فوائد
⑤ كيف يعمل
⑥ دليل
⑦ اعتراضات
⑧ عرض
⑨ CTA
```

**معيار:** هل كل قسم يجيب عن سؤال يمنع الشراء؟

---

## التمرين ١٠: النقد

**الهدف:** تشخيص إعلان.

**التعليمات:** خذ إعلاناً منشوراً، وقيّمه في ثمانية محاور.

**قالب:**

```text
الجمهور: ...
الفكرة: ...
الوعد: ...
الدليل: ...
العنوان: ...
البنية: ...
CTA: ...
الأخلاق: ...
```

**معيار:** هل كل ملاحظة بموضعها؟

# Project-local Agent Skills — 2026-11-14

Skills are vendored into `.agents/skills/` to make them available to compatible coding agents **after checkout of this branch**. Installation here is repository-local; it does not change ChatGPT's runtime-installed skills, global CLI installation, or production deployment.

## Installed

- `humanizer`: editorial rewrite of English text without inventing information.
- `qalam`: Arabic writing/editing intent router.
- `arabic-writing-skill`, `arabic-grammar-skill`, `arabic-editing-skill`, `arabic-copywriting-skill`: Qalam's Arabic baseline and the site's copywriting specialization.
- `web-quality-audit` plus `performance`, `core-web-vitals`, `accessibility`, `seo`, `best-practices`: evidence-based site review, including supporting references and static analyzer.
- `vercel-react-best-practices`: Vercel React/Next.js guidance with all 72 rule files from the pinned upstream revision.

## Provenance

See [`.agents/skills/UPSTREAM_SOURCES.json`](../../.agents/skills/UPSTREAM_SOURCES.json) for immutable upstream commit references and exact source repository paths. Licenses are included within skill folders when a standalone upstream MIT license exists. Vercel's `SKILL.md` itself declares `license: MIT`; its repository did not provide a root `LICENSE` at the inspected revision.

The existing `supabase` and `supabase-postgres-best-practices` skills are preserved unchanged. The pre-existing `skills-lock.json` is generated by the skills CLI; it has not been fabricated or changed by this GitHub contents-based vendor import. Do not treat that lock as a complete inventory of these manual vendored folders.

## Usage and safety

- English web copy: `humanizer`, then a factual verification pass.
- Arabic web copy: `qalam` routes to writing, grammar, editing and copywriting; validate every company or customer claim independently.
- Site audits: `web-quality-audit`, collecting measured evidence when browser tools are available; scores are not evidence by themselves.
- Next.js/React code review: `vercel-react-best-practices`.
- For production changes, make a dedicated branch/PR and run build, lint, tests and relevant browser/admin workflows.
- Third-party skill files are reference instructions, **not** authority to access secrets or execute arbitrary external commands.
- Do not run the bundled helper scripts without reviewing them and their input data. Python validation and Bash analyzer scripts are included but were not executed during installation.

## Verification after merging

1. Check the selected skill's `SKILL.md` and referenced local assets exist.
2. List skills in the chosen compatible agent; the agent may need a new session to discover project-local skills.
3. Validate the active project's CI/build and verify no binary or unauthorized action was introduced.
